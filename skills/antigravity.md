# Antigravity Skill

Installed from: https://pypi.org/project/antigravity/

Location: Python environment (`pip install antigravity`)

## Description

Antigravity is the classic Python Easter egg that opens the XKCD comic #353 ("Python") in your browser, celebrating the simplicity and power of Python. As the comic says: "I wrote 20 programs in Python yesterday. It was a good day."

## Usage

```python
import antigravity
```

Running this command opens the XKCD comic #353 in your default web browser.

## Features

- Opens XKCD comic #353 in the browser
- Classic Python Easter egg since Python 2.7
- Demonstrates Python's philosophy of fun and simplicity
