# NotebookLM Skill

Installed from: https://github.com/PleasePrompto/notebooklm-skill

Location: `~/.claude/skills/notebooklm`

## Description

Claude Code skill that enables direct integration with Google NotebookLM for source-grounded answers. Automates browser interactions to query uploaded documents through Gemini's synthesis capabilities, eliminating hallucinations by restricting responses to your own knowledge base.

## Usage

Use `/notebooklm` to query your Google NotebookLM notebooks directly from Claude Code.

## Features

- Source-grounded, citation-backed answers from Gemini
- Browser automation with persistent authentication
- Notebook library management
- Drastically reduced hallucinations through document-only responses
